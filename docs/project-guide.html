PROJECT WALKTHROUGH

Test Iranian payments and OTP flows without credentials or live transactions.

  1. Keep the service local

    Start the emulator and point only your development configuration at http://localhost:8585. Keep production provider URLs separate.

    npx github:mrzroot/mihanstack

  2. Exercise retry handling

    Run the duplicate_callback scenario, or use the webhook command to call your own development handler twice. The expected outcome is one order transition, not two.

  3. Observe delivery locally

    Generate an OTP through the emulator, then fetch the last simulated message from the local admin API. Use test-only numbers and no production credentials.

    curl 'http://localhost:8585/_mihan/sms?receptor=09120000000&last=1'
راهنمای عملی پروژه

پرداخت و رمز یک‌بارمصرف را بدون کلید واقعی و تراکنش زنده امتحان کنید.

  1. اجرای محلی

    فقط تنظیمات توسعه را به localhost:8585 وصل کنید و نشانی سرویس‌های واقعی را جدا نگه دارید.

    npx github:mrzroot/mihanstack

  2. آزمون پردازش تکراری

    سناریوی duplicate_callback را انتخاب کنید و مطمئن شوید سفارش با دریافت دوبارهٔ callback فقط یک‌بار تغییر وضعیت می‌دهد.

  3. مشاهدهٔ پیام آزمایشی

    رمز آزمایشی بسازید و پیام آخر را از API محلی بخوانید؛ از اطلاعات و شماره‌های واقعی استفاده نکنید.

    curl 'http://localhost:8585/_mihan/sms?receptor=09120000000&last=1'
